# RKG Inspector
An advanced Mario Kart Wii ghost data viewer and modifier. RKG Inspector is able to read all data stored in a Mario Kart Wii ghost file, including extra data written by [CTGP Revolution](https://chadsoft.co.uk/), [Retro Rewind](https://rwfc.net/), and [Mario Kart Wii Service Pack](https://mkw-sp.com/). Supports the modification of base ghost metadata fields such as the track, finish time, lap times, character/vehicle combo, controller used, and more.
